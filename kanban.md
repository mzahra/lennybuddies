# Kanban Workflow — Lenny Buddies

## How we worked

We ran this project as a single shared Trello board, following a Kanban-style flow across four lists: **Backlog → In Progress → QA/Review → Done**. Cards were kept granular rather than one big "build the project" card — things like *"Build document_processor.py for Markdown document ingestion and processing"*, *"Advanced prompt engineering templates"*, and *"LLM API integration"* — so at any point it was clear exactly which piece of the pipeline (data ingestion, knowledge base, prompts, generation) was in motion and who owned it.

Each card was assigned to a specific team member (initials shown on the card), and cards moved left to right as work progressed — from an idea in the Backlog, through active development in In Progress, a QA/Review pass, and finally Done once verified. We captured the board at two checkpoints during the project to show that progression over time.
